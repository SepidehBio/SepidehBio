Selected Research Directions

Clinical & Biomedical Data

Designing reproducible pipelines for biomedical datasets, including data validation, preprocessing, feature engineering, machine-learning workflows, evaluation, automated testing, and reproducible execution.

Single-Cell & Graph Learning

Developing graph-based approaches for cellular representation learning and cell-state classification from single-cell transcriptomic data.

Genomic Language Models

Working with biomedical language models and genomic variation data, including parameter-efficient fine-tuning and large-scale genomic data processing.

Mechanistic Computational Biology

Implementing mathematical and computational models to study biological state transitions, heterogeneity, and emergent phenotypes.

Research Software Principles

I aim to develop scientific software that is:

- Reproducible
- Testable
- Modular
- Documented
- Version-controlled
- Automated
- Containerized when appropriate
- Scalable when required

A scientific workflow should make computational decisions traceable, reproducible, and inspectable — not simply produce a final result.
